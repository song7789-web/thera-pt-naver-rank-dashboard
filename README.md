# 테라PT 언주역점 네이버 순위 대시보드

테라PT 언주역점의 네이버 키워드별 순위를 확인하기 위한 대시보드입니다.

## 무료 운영 방식

이 프로젝트는 ChatGPT나 OpenAI API를 사용하지 않습니다. 다만 실제 네이버 플레이스 목록을 여러 키워드로 반복 조회하면 보안확인 또는 접근 제한이 발생하므로, 현재 GitHub Actions는 자동 예약 실행을 중단하고 수동 점검 전용으로 설정했습니다.

1. `.github/workflows/collect-naver.yml`을 기본 브랜치에 올립니다.
2. Actions에서 `네이버 실제 순위 수동 점검`을 실행할 수 있습니다. 보안확인이 발생하면 즉시 중단하고 임의의 순위를 저장하지 않습니다.
3. 공개 웹은 검증된 새 형식(`version: 2`)의 `dashboard.json`만 읽습니다. 예전 지역검색 API의 1~5번째 결과는 실제 플레이스 순위로 표시하지 않습니다.

## 범위와 제한

- 순위는 네이버 플레이스 모바일 관련도순에서 광고를 제외한 업체 카드 순서입니다. 최대 50위까지 확인합니다.
- 검색 위치에 따라 순위가 달라지므로 테라PT 언주역점 좌표를 기준으로 고정해 매일 같은 조건에서 비교합니다. 로그인 여부, 시간, 개인화에 따라 사용자가 직접 보는 순위와는 차이가 날 수 있습니다.
- 네이버가 보안확인이나 접근 제한을 표시하면 수집이 실패합니다. 이 경우 임의의 순위를 저장하지 않고 `확인 필요`로 남깁니다.
- 전체 키워드의 정확한 매일 자동 수집은 현재 무료 공식 API만으로 구현할 수 없습니다. 실제 순위를 무료로 유지하려면 사람이 확인한 값을 입력하는 방식이 가장 안전합니다.
- NAVER API HUB 공개 응답에는 방문자 리뷰 수와 플레이스에 수집된 블로그 리뷰 수가 포함되지 않아 리뷰 수는 화면의 직접 입력 기능으로 기록합니다.
- GitHub는 무료 정책과 한도를 변경할 수 있으므로 “평생 무료”를 보장할 수는 없습니다. 공개 저장소의 표준 GitHub-hosted runner는 현재 무료이지만, 공개 저장소의 예약 워크플로는 60일 동안 활동이 없으면 자동 비활성화될 수 있습니다.
- 기존에 등록한 네이버 API 키는 이번 순위 수집에는 사용하지 않습니다.
